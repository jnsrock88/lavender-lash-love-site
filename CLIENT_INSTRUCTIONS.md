# Updating the Lavender Lash Love Website

You can open a fresh Codex chat inside this project and describe the change you
want in everyday language. No coding terms are needed.

You can ask Codex to:

- replace or add a picture
- change hours, contact details, prices, booking links, or service information
- add a testimonial or gallery image
- edit a sentence
- hide or remove a service
- make a small, specific visual adjustment

## Replacing a picture

Attach the new image to your Codex message and say where it should go. For
example:

> Replace the first picture on the homepage with this photo.

If possible, mention the page and the picture’s role, such as “homepage hero,”
“About Jen portrait,” or “Thousand Oaks location photo.”

## Example requests

- Change my Friday hours to 11:00 AM–7:00 PM.
- Raise the Volume 2 Week Fill price to $140.
- Add this photo to the gallery.
- Replace my About Jen photo with the attached picture.
- Change my phone number to 555-555-5555.
- Add this client testimonial: “...”
- Make the logo slightly larger on mobile.

Codex will make the requested update, test it, commit it to GitHub, and push it
to the `main` branch. Cloudflare then publishes the updated preview. Changes
may take a few minutes to appear.

Live preview:
[lavender-lash-love-site-lub.pages.dev](https://lavender-lash-love-site-lub.pages.dev)

Do not request production-domain changes unless you are intentionally ready to
launch the website.

## When Codex may ask a question

Codex may ask one short question when a request has more than one reasonable
meaning—for example, if “the first picture” could refer to two different
sections. A little detail about the page, image, or location usually avoids
this.

Vague requests such as “make it better” or requests that could change several
parts of the site may need clarification before Codex proceeds.

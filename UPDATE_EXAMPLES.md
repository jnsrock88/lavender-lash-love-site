# Safe Update Examples

## Replace the homepage hero

**Owner says:** Replace the first picture on the homepage with this attached photo.

**Codex should:** Treat “first picture” as the homepage hero, inspect the current desktop and mobile crops, add the image with a clear filename, update the central media registry and asset inventory, preserve the layout, test both viewport sizes, and publish the verified change.

## Replace an About Jen photo

**Owner says:** Replace the working photo on About Jen with this one.

**Codex should:** Replace only the specified About image, preserve the hero and other portraits, protect important facial and hand details in the crop, update the media registry and asset inventory, and test the About page.

## Add a gallery photo

**Owner says:** Add this client photo to the gallery after the second image.

**Codex should:** Add the file with a clear name, register it centrally, insert it in the requested position without changing the gallery design, supply accurate alt text from the provided context, update the asset inventory, and test the gallery and lightbox.

## Change hours

**Owner says:** Change my Studio City Friday hours to 11:00 AM–7:00 PM.

**Codex should:** Update only the Studio City Friday schedule in the central business-content record, confirm every page reads the centralized value, and avoid inventing any other hours.

## Change prices

**Owner says:** Change the Volume 2 Week Fill price to $140.

**Codex should:** Update that single offering in the centralized service menu, verify every displayed instance uses the new value, and leave all other services and prices unchanged.

## Update phone or email

**Owner says:** Change my email to new@example.com.

**Codex should:** Update the display value and matching `mailto:` link in the centralized contact record, verify the footer and Contact page, and change nothing else.

## Add a testimonial

**Owner says:** Add this testimonial from Maria: “My lashes look beautiful and feel so natural.”

**Codex should:** Add only the supplied quote and attribution to the centralized testimonial content, without inventing a rating, date, location, or additional endorsement, then test its presentation.

## Change a service description

**Owner says:** Change the Classic Lashes description to: “A soft, polished enhancement for everyday wear.”

**Codex should:** Replace only that description in the centralized service record and verify every page that displays it.

## Temporarily hide a service

**Owner says:** Temporarily hide Lash Removal from the website.

**Codex should:** Hide only that offering through the central service configuration, preserve its information for easy restoration when practical, and verify it no longer appears publicly.

## Update a booking link

**Owner says:** Change the Thousand Oaks booking link to https://example.com/new-booking.

**Codex should:** Update only the Thousand Oaks URL in the centralized booking record, verify all Thousand Oaks buttons use it, preserve the Studio City link, and confirm external-link behavior.

## Change a location photo

**Owner says:** Replace the Studio City location photo with this attached image.

**Codex should:** Replace only that location image, retain the current layout and location facts, choose safe desktop and mobile crops, register the asset centrally, update the asset inventory, and test every place the photo appears.
